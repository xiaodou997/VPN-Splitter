# 技术验证证据

当前没有已执行的 VPN、签名或网络兼容性证据。此目录只提供填写规范与模板，不代表 S0–S5 已通过。

每次验证复制 [template.md](template.md)，建议命名为 `S0-YYYYMMDD-short-name.md`。每份记录引用开发任务和 [测试 ID](../test-plan.md)，包含环境、步骤、预期与真实观察、恢复结果、结论和遗留问题。

状态只能是 PASS、FAIL、BLOCKED、NOT RUN、NOT APPLICABLE。NOT APPLICABLE 必须写理由；不能用于豁免发布必需能力。演示视频、路由表、源码可编译各自只能支持对应层面的结论，不能互相替代。

公开仓库只保存脱敏结果和合成配置。禁止上传有效 .conf/.ovpn、私钥、密码、令牌、认证回调、完整企业域列表、未脱敏日志或全量抓包。原始材料留在有授权的本地位置，以本地引用标识关联，不把私有路径或机密链接写入公共记录。

证明出口时尽量使用用户控制的服务端记录或限定范围的链路观察，并说明这种证据的局限。未测 IPv6、DNS、重连等必须逐项列出。

阶段关闭由实际执行者和维护者依据证据确认；模板中不得预填成功结论。
