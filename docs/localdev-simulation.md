# LD-03B：模拟连接、取消、超时与重试

这是本地交互测试，不是真实 VPN 后端。只从 main 更新，窗口标识为 LD-03B。无需真实配置、Team ID 或凭据；模拟不会访问 Keychain，不建立隧道，不发送 DNS 查询，也不改变路由。

## 使用入口

选择或新建空白策略，展开页面底部的“开发工具（模拟与合成示例）”。选择本次场景，再点“开始模拟”。按钮会根据状态变为取消、停止或重试；一次只允许一个尝试。

| 场景 | 检查通过后的预期过程 |
| --- | --- |
| 正常成功 | 约 1 秒后显示模拟成功；明确不代表 VPN 已连接 |
| 认证失败（注入） | 约 1 秒后显示注入的认证失败，没有联系服务器 |
| 连接超时（不返回结果） | 约 3 秒后显示等待超时，允许手动重试 |
| 成功后中断（注入） | 约 1 秒后模拟成功，再约 1 秒后显示模拟连接中断 |

启动前执行真实 PolicyCore 的同步规则/配置检查，包含已导入配置的范围约束。检查失败时没有启动模拟定时器，错误继续显示在检查页。“检查配置中”通常一闪而过，不代表异步 DNS 或认证。同步检查期间没有可抢占取消能力；3 秒计时从检查通过、模拟驱动启动后开始。

计时不是实时调度保证；主线程繁忙时可能稍晚更新界面。成功回调也检查单调时钟期限，所以超过截止时间的结果不会因为先出队而显示成功。

## 取消、停止和失效

连接中点“取消模拟”，立即使当前连接回调失效，约 250 毫秒后从“停止中”变为“已取消”。成功后点“停止模拟”，同样经过停止中，回到未开始。250 毫秒只是演示确认，不代表真实系统隧道已经撤销。停止中不允许重复开始或停止；已取消、超时、失败后可以手动重试。

超时、失败及中断没有自动重连。重试重新编译完整策略，生成新的尝试与计划标识，不沿用旧的成功结果。旧成功、旧超时、重复完成和旧停止回调不能结束新尝试。

成功保存规则/参数、切换或删除策略、重新检查、进入编辑窗口，以及开始凭据操作，会结束旧模拟。进入编辑或凭据操作本身就会停止模拟，即使随后取消编辑或保存失败，也不自动恢复。工作区持久化失败仍不接受失败编辑；原规则和凭据恢复边界不变。

“模拟网络变化”是手动注入事件：清掉旧预览并结束模拟，必须重新检查或手动重试。它没有读取 Wi-Fi/网卡、真实网络 epoch、睡醒通知或系统路由。关闭窗口不等于退出；真正批准退出后取消内存定时任务，未保存编辑的退出保护仍生效。

## 过程记录与数据

展开“模拟过程”查看最近 32 个事件，顺序从旧到新，超出上限丢弃最旧项。只记录固定事件名称，不记录策略名称、目标、原始错误、密钥、凭据引用或访问地址。“清空模拟记录”仅清空显示历史，不停止正在进行的模拟。

工作区 JSON 不写模拟状态、尝试或记录；重启只恢复已保存策略，不恢复连接。本批不新增工作区版本，原 .conf 不修改。任何模拟成功都不是 Keychain、服务器认证、双出口、DNS 或真实撤销的证据。

## Mac 人工清单（本批原生交互待验）

1. 新建空白策略，使用正常成功场景，确认开始后不能重复开始，约 1 秒后显示“模拟：连接成功（不代表 VPN 已连接）”；停止后回到未开始。
2. 再开始后立即取消。观察超过 3 秒，不应被迟到回调重新变为成功。取消期间点击开始应不可用。
3. 选择连接超时，等待超时；改为正常成功并重试，应生成新尝试并成功。选择认证失败、成功后中断，错误提示应各自对应，不自动重连。
4. 模拟中进入规则编辑、切换策略或点“模拟网络变化”，旧模拟应失效；旧预览是否保留取决于是否仅进入编辑还是配置/网络意图已经失效。失败输入不保存到磁盘。
5. 展开过程记录并清空，确认清空不会停止模拟；退出重开，过程记录与模拟状态不恢复。既有批量规则、搜索、参数及 Keychain 清单仍分别验收。

这些是待执行步骤，不是自动通过的记录。无需为了本轮模拟导入真实配置或授权 Keychain。
