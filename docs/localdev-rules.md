## 批量添加

选择一份策略 → 规则 → 批量添加。每行一个 IPv4 地址或 CIDR，例如：

```text
# 合成示例，不会访问这些地址
198.51.100.7
203.0.113.0/24
```

选择统一动作“走 VPN”或“直连”，查看数量与规范化后的目标，再点“确认追加规则”。默认动作是当前默认出口的相反动作。每批最多 64 KiB，保存后的整份策略最多 1000 条；空行与以 # 开头的整行注释忽略。支持 UTF-8 BOM、LF、CRLF 和 CR 换行。

仅支持 IPv4，每行不接受动作列、URL、域名、IPv6、脚本或行尾注释。出错显示原始行号，不回显错误行内容；任一错误使整批不能保存，不会先导入前面的有效行。修正后可直接重试，取消脏编辑仍需确认。

例如 `198.51.100.7/24` 会保存为 `198.51.100.0/24`，覆盖的是网段而不是单个主机，界面会提醒并允许展开核对。重复条目不自动去重，原始顺序保持。新增规则只追加在末尾，因此可能被前面的规则遮蔽；保存后使用“检查规则”查看，必要时上移。

追加不会改名称、默认出口、已有规则 ID、WireGuard 结构、AllowedIPs、Keychain 引用或待清理记录。保存通过已有的单编辑事务；对象变化或磁盘写入失败时，不覆盖已接受数据。编辑期间不能切换策略或进行凭据操作。未完成的内存输入不保证在强制退出/崩溃后恢复。

批量输入需全部格式正确才保存；这比单条草稿编辑更严格。格式正确不代表 Peer 范围、基础设施要求或真实网络检查已通过，仍需单独点击“检查规则”。

## 搜索

规则页搜索匹配目标文本、类型、VPN/DIRECT、走 VPN/直连、已启用/已禁用；不区分拉丁字母大小写。显示原始规则编号及“显示数量 / 总数”。搜索不会解析域名、访问目标、改变保存顺序或禁用隐藏规则，检查始终使用全部规则。

为避免把“上移”误认为只在筛选结果间移动，搜索期间暂停排序；清除搜索后恢复。编辑、启用/禁用和删除仍针对明确的原规则 ID；删除照常确认。搜索词不写入工作区。
