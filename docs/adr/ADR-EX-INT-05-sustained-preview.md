# ADR-EX-INT-05：可持续 IP 分流试用会话

日期：2026-09-30。状态：Accepted（用户要求优先交付试用，实施/真机证据另记）。

新增显式签名构建选项 sustained；默认只读与既有 60 秒 route-trial 保持原行为。持续模式没有绝对运行时限，但必须由已认证、当前 console user 的同一控制连接持有。10 秒心跳失联、主动停止、App 退出/睡眠、网络 epoch 变化与观察失败仍撤销；不自动重连或重放规则。一次一个会话，数量/前缀/地址预算不扩大。

持续模式只允许主机端构建选择；IPC 请求不能设置持续时间。原生事务采用明确的受控生命周期选项，CLI 默认仍限 60 秒。后台进程不能依靠旧 marker 恢复删除权。硬崩溃仍可能留下记录，按现有恢复流程处理，不提供系统 Kill Switch。

长连接仅在服务确认对应活动会话且心跳新鲜时免于 120 秒通道寿命上限；未授权、空闲、已取消连接保持原限额。请求增加严格递增序号，避免每秒状态查询累计无界 UUID 集合；状态请求用序号防重放，变更请求仍保留有限 UUID 防重放集合。旧无序号协议仅用于原有有限实验；持续模式拒绝无序号客户端。计数溢出拒绝，不能回绕。

UI 明确显示持续试用、依赖 App 运行、停止/网络变化撤销；只有原生成功回复才显示生效。交付前关键门槛：超过 60/120 秒和 512 次状态查询仍正常；停止、失联、网络变化、序号重放拒绝与默认短租约回归；实际签名、公证、安装及持续运行/停止验证。完整发行稳定性不冒充已完成，第三方客户端缺陷不作为本试用版功能开发阻塞。

停止后允许最多 10 秒的终态回复送达窗口，固定从会话结束计时，不因状态查询续期；此窗口不保有活动路由。真实跨 120 秒停止时发现通道清理与回复送达竞态，因此纳入实施约束。
